## 📖 Сюжет

Давным-давно боги времени установили своё владычество над вселенной. Они играли судьбами смертных, как пешками в своей вечной игре. Но однажды они совершили роковую ошибку — уничтожили всё, что ты любил.

Теперь ты поднимаешься по **Хроноспирали** — лестнице между мирами — чтобы достичь Престола Хроноса и свергнуть повелителей времени.

---

## ✨ Возможности

### ⚔️ Геймплей
- **3 уникальных класса** — Воин, Маг, Ассасин — с разными статами и стартовыми предметами
- **5 уровней сложности** — от «Лёгкой» до «Невозможной» (открывает скрытого босса)
- **Пошаговые бои** — критические удары, уклонение, защита, система баффов
- **Анализ боя** — прогноз исхода сражения в реальном времени
- **Прокачка** — уровни, очки характеристик, магазин с 13 предметами
- **8 локаций** — бои, сундуки, отдых, финальный и скрытый боссы

### 🎨 Визуал и звук
- **Красивый UI** через `rich` — цветные HP-бары, панели, таблицы
- **Эффект печатающей машинки** — сюжетные сцены печатаются с реалистичными опечатками
- **Процедурная музыка** — генерируется при первом запуске (спокойная вне боя, напряжённая в бою)
- **Цветные концовки** — победа, абсолютная победа, поражение

### 🛡️ Механики
- 🔥 **Ярость** — +100% к атаке на 3 хода
- 🛡️ **Неуязвимость** — иммунитет к урону на 2 хода
- 🪨 **Каменная кожа** — +50% к защите
- 💫 **Ослабление** — -50% к атаке врага
- ✨ **Свиток времени** — снимает все баффы с противника

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- Windows / Linux / macOS

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/4ekHyTblu-xXx6o55xXx/Chronospire.git
cd Chronospire

# 2. Создать виртуальное окружение
python -m venv .venv

# Windows:
.venv\Scripts\activate
# Linux/Mac:
# source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить игру
python main.py
```
> 💡 **Windows-лаунчер:** скопируй `play.bat.example` → `play.bat`, затем запусти двойным кликом.

**Первый запуск займёт 5–10 секунд** — сгенерируются `calm.wav` и `battle.wav` в папке `assets/`.

## 🎮 Управление

Игра полностью текстовая — следуй инструкциям на экране, выбирай опции цифрами.

**В бою:**

| Кнопка | Действие |
|:---:|:---|
| `1` | ⚔️ Атаковать (шанс крита 10%) |
| `2` | 🧪 Использовать предмет |
| `3` | 📊 Анализ боя — прогноз исхода |
